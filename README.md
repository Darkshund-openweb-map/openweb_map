# WEB SCOPE — 오픈웹 플로우 V4

오픈웹 플랫폼과 관련 사건, 플랫폼 사이의 연결 관계를 한곳에서 살펴보는 생태계 지도입니다. 지도를 따라 탐색하거나 검색으로 원하는 항목으로 바로 이동할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버 주소는 실행 시 터미널에 표시됩니다.

## 화면 구성

### 생태계 지도

플랫폼 유형은 섬으로, 개별 플랫폼은 섬 안의 영토로 표시됩니다. 섬을 선택하면 포함된 플랫폼을 둘러볼 수 있고, 영토를 선택하면 해당 플랫폼에 집중해 사건과 연결 관계를 확인할 수 있습니다. 관계선을 선택하면 관계 유형과 검토 상태, 근거를 보여주는 카드가 열립니다. `전체 관계 보기`로 현재 선택한 영역의 관계를 더 넓게 살펴볼 수 있습니다.

지도를 드래그해 이동하고 휠이나 트랙패드로 확대·축소할 수 있습니다. 화면 아래의 확대·축소 버튼과 `전체 보기` 버튼으로 화면을 조정할 수도 있습니다.

### 상세 정보

섬이나 플랫폼을 선택하면 상세 패널에서 다음 내용을 볼 수 있습니다.

- **개요:** 사건 수, 최근 관측일, 노출 정보 유형과 추이
- **사건:** 최신순 사건 목록과 설명, 기간 선택 및 시작일·종료일 필터
- **연결:** 관련 플랫폼과의 관계, 관계 유형과 검토 상태

관계는 검토 완료와 검토 전 상태를 구분해 표시합니다. 등록된 사건이나 관계가 없는 영역에는 빈 상태 안내가 나타납니다.

### 검색과 통계

상단 검색창에서 플랫폼, 사건, 연결 관계를 검색하고 결과를 선택해 해당 화면으로 이동할 수 있습니다. 검색창은 `Ctrl+K` 또는 `⌘K`로도 열 수 있습니다.

상단의 `지도`·`통계` 버튼으로 화면을 전환합니다. 통계 화면에서는 플랫폼 유형별 사건과 노출 유형의 분포, 최근 주요 사건을 살펴보고 항목을 선택해 관련 상세 화면으로 이동할 수 있습니다.
